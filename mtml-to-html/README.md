# MHTML to HTML
1.

I need to take a screenshot of HTML file my Android phone. By default, Android can not open MHTML.

This script converts an MHTML file to HTML

2.
Download the HTML file from the web but saves as a folder
wget -E -H -k -K -p https://colon-analogy-notation.personal-website-a13.pages.dev/bitsbipsbricks/Colon-Analogy-Notation

3. This is best option and what I am going to go with

monolith https://colon-analogy-notation.personal-website-a13.pages.dev/bitsbipsbricks/Colon-Analogy-Notation -o Colon-Analogy-Notation.html

See:
- [monolith](https://github.com/Y2Z/monolith)
